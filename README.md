# ｲｷﾘﾌﾚｰﾑ

写真にロゴや撮影情報を添えて、自分好みのフレームで書き出せるAndroidアプリです。

**Android 7.0以降に対応。** 写真の処理は端末内で完結し、元の写真は変更しません。

## できること

- 撮影機種・焦点距離・F値・シャッタースピード・ISO・撮影日時を表示
- ラベルの編集と、好きなロゴの追加（SVG・PNG）
- 写真から抽出したカラーや、お好みのカラーパレットで配色を変更
- フレームの太さとライト／ダークの切り替え
- 拡大プレビューで確認して、JPEGで保存

撮影情報がない項目は空欄になります。

## 使い方

1. 「イキる写真を選ぶ」から写真を選びます。写真アプリの共有メニューからも開けます。
2. ロゴ・ラベル・太さ・カラーを調整します。
3. 「書き出し」で保存します。

Android 10以降では `Pictures/IkiriFrame` に保存されます。Android 7〜9では保存先を選択します。

## ビルド

Android Studioでプロジェクトを開き、Android SDK Platform 37をインストールしてください。

ホーム画面の3Dモデルはライセンス上の理由でこのリポジトリに含めていません。先に[モデルの準備手順](assets/home-emoji/README.md)に従って素材を用意してください。

```sh
./gradlew :app:assembleDebug
```
